# Web-Robomart-clone

This is a clone of Robomart.com. It is a static electronics storefront with a catalog, product categories and a sample order-tracking form.

## Local preview

From the repository root, run the following command, then open [localhost on port 8000](http://localhost:8000/).

```sh
python -m http.server 8000
```

## Browse the project

| Page | Source |
| --- | --- |
| Storefront | [index.html](index.html) |
| Electronic components | [electronic-components.html](electronic-components.html) |
| Robot kits | [robotkit.html](robotkit.html) |
| Sample order tracking | [track-your-order.html](track-your-order.html) |
| Company and contact | [About](about.html) and [Contact](contact.html) |

[style.css](style.css) contains the shared site styles. The tracking form demonstrates browser input and validation. Connecting orders or submitting contact requests requires a backend.
